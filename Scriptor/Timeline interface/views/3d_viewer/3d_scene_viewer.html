Scene Maker JS API Console Commands

You can open the browser developer console (F12) and execute commands on window.sceneAPI:

// 1. Spawn Blocks Programmatically let light = sceneAPI.spawnLight({ x: 0, y: 5, z: 0, color: '#38bdf8', isLocked: true }); let cam = sceneAPI.spawnCamera({ x: -6, y: 4, z: 0, fov: 60, range: 25 }); let target = sceneAPI.spawnTarget({ x: 0, y: 1.5, z: -8, isLocked: true }); // 2. Rotate & Modify sceneAPI.rotateObject(light.id, -30, 45, 0); sceneAPI.setLightColor(light.id, '#f59e0b'); sceneAPI.setObjectPhysics(target.id, true); // Disable physics sceneAPI.setLightAngle(light.id, 60); sceneAPI.setLightIntensity(light.id, 6); sceneAPI.setCameraRange(cam.id, 30); sceneAPI.setCameraTrackMode(cam.id, 'pair'); // or 'between' sceneAPI.setLightBeamLength(light.id, 25); // 3. Spawn Areas (bounded zones that hold targets) let area = sceneAPI.spawnArea({ x: 0, y: 0.5, z: -6, mode: '2D', width: 8, height: 3, rotation: 30 }); area.spawnTarget(); // next free cell area.spawnTarget({ x: 1, y: 0, z: 0 }); // from the left-bottom corner, in blocks area.spawnTarget({ cell: [2, 1, 0] }); // by cell index area.spawnTargets(5, { isLocked: false }); area.targets.forEach((t, i) => t.setLocal(i, 0, 0)); // (0,0,0) = left-bottom cell area.targets[0].setRotation(90); // degrees, around Y area.targets[1].setLocked(false); area.removeTarget(2); area.setTargetCollision(true); // targets are solid to each other (default: they pass through) area.setMode('3D'); area.setSize({ width: 6, height: 3, depth: 4 }); sceneAPI.getAreas(); // every spawn area // 4. Save / Load Scene sceneAPI.saveScene(); sceneAPI.loadScene();
